saya ingin buat aplikasi mobile Sayang Anak dengan ketentuan yakni 1 aplikasi ada 2 mode yakni mode orang tua dan mode anak dengan nama aplikasi Sayang Anak `com.googlehome.parent` nama aplikasi di samarkan menjadi `Google Home`
di awal setelah apliaksi di install akan bertanya di install sebagai mode apa? Parent atau Kids
**Mode Parent**
1.  akan memantau lokasi hp anak dengan memasukkan kode unik/ID hp anak
2. fitur parent akan memantau secara realtime update setiap 10 detik sekali untuk lokasi
3. fitur parent ada tombol navigasi ke maps 
4. dan ada fitur penambahan anak untuk orang tua dengan anak lebih dari 1
5. ada tombol trigger notifikasi untuk mengaktifkan aplikasi anak jika aplikasi di hp anak tidak berjalan di background
6. perjalanan anak akan di simpan setiap hari di lokal dan bisa dibuka di menu riwayat 

> [!important] Mode
> Mode ini hanya sekali pakai dan akan berjalan seterusnya jika pilih parent maka akan selalu parent, jika waktu awal dibuka setelah instalasi pakai mode anak/Kids maka akan permanen menjadi mode kids

**Mode Anak/Kids**
1. aplikasi akan menampilkan awal pemilihan mode setelah di install
2. pastikan pilih mode anak
3. dan aplikasi akan langsung bekerja di balik layar mengirimkan data lokasi setiap 10 detik ke aplikasi parent jika orang tua membuka aplikasi
4. aplikasi akan melacak kemana saja anak pergi agar oreang tua tidak hawatir dengan konsisi anak dan dimana dia sekolah atau membolos atau kemana tanpa harus susah payah menghubungi jadi orang tua langsung tahu lokasi anak dimana
5. aplikasiberjalan dilatar belakang gunakan apapun caranya agar apliaksi aktif terus
6. layar utama di sembunyikan dengan seperti sistem update yang selalu berubah tanggal updatenya random dalam bulan itu misal dia buka tanggal 7 april maka aplikasi akan merandom antara tanggal dan bulan maret hingga h-1 tanggal aplikasi
7. buatkan easter egg untuk membuka Childs ID yang hanya diketahui oleh orang tua saja misal harus menahan tombol atau tulisan update sistem selama 10 detik atau lebih (ingat ini hanya diketahui oleh parent, aplikasi Kids tidak akan menampilkan clue apapun)

> Sebagai AI yang ahli di bidang mobile anda diwajibkan mematuhi syarat Google Play dan gunakan arsitektur MVVM
